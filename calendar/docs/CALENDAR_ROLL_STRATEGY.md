# 季节性日历策略：交割月 & 换月（非天气）

> 更新：**2026-09-14**  
> 定位：与量价 / 新闻 / 天气 / 宏观 **正交的第五类** —— 合约制度与期限结构 mechanics  
> 数据：`calendar/data/panels/` · 搜索：`calendar/code/search_calendar_strategies.py`  
> 相关：`spread/docs/SPREAD_STRATEGY.md`（近远月 carry 均值回归，无日历门控）

---

## 1. 与现有四腿的区别

| 维度 | 天气 v3 | 宏观 A | spread carry | **calendar（本文）** |
|------|---------|--------|--------------|---------------------|
| 驱动 | 产区温降水 | 美元广度 | 价差 z 偏离 | **换月窗口 / 交割月 / 日历月** |
| 品种 | 棉糖苹果枣 | AU | RB/HC/AU… | 多品种，偏 **低保证金** 池 |
| 与 Core 关系 | 农产品正交 | 贵金属正交 | 期限 vs 截面 | **事件门控**，有仓日更低 |

**不包含**：物候、种植收获（归天气腿）；纯宏观日历（归宏观/FRED）。

## 2. 因子与事件定义

构建脚本：`calendar/code/build_calendar_panels.py`  
配置：`calendar/config/calendar.yaml`

### 2.1 合约层级

| 字段 | 含义 |
|------|------|
| `near_code` / `far_code` | 当日按到期排序 rank1 / rank2 |
| `main_code` | `pick_main_fast` 主力（月+3 规则，与量价一致） |
| `carry_pct` | (近−远)/近 |
| `carry_z20/60` | carry 滚动 z |
| `near_oi_share` | 近月 OI / (近+远 OI) |

### 2.2 日历事件

| 事件 | 定义 | 典型用途 |
|------|------|----------|
| **`in_roll_window`** | 主力 `main_code` 切换日前后各 5 个交易日 | **换月 carry 均值回归**（首选） |
| **`pre_roll`** | 切换日前 5 日 | 移仓压力、OI 再分配 |
| **`in_deliv_month`** | 日历月 = 近月合约交割月 | 交割月基差/仓单逻辑 |
| **`pre_deliv`** | 交割月前 ≤15 个自然日 | 近月升贴水收敛 |
| **`cal_month`** | 1–12 月 | 非天气 **日历月** 效应（如 I 的 11 月） |

主力规则：`trade_month + roll_offset(=3)` 之后最近到期合约为准（见 `linear_ridge_walkforward.pick_main_fast`）。

## 3. 策略族（规则模板）

### 3.1 ★★★ 换月窗口 Carry 均值回归（定稿候选）

**逻辑**：移仓期近远月价差波动放大，极端 `carry_z` 倾向均值回归（与 spread 同因子，但 **仅在 `in_roll_window` 开火**）。

```
若 date ∈ roll_window 且 |carry_z20| ≥ thr：
    仓位 = −sign(carry_z)   # 做多/空 carry（多近空远 或 反向）
持有 hold 日（搜索最优多为 1 日）
```

**2018→2026 单品种最优（roll 门控）**

| 品种 | thr | hold | Sharpe | 收益(100万) | 有仓占比 | 最差日 |
|------|-----|------|--------|-------------|----------|--------|
| **HC** | 0.75 | 1 | **2.87** | +11.3% | 24% | −1,880 |
| **AG** | 1.0 | 1 | **2.34** | +7.6% | 10% | −1,770 |
| **AU** | 0.75 | 1 | **2.33** | +51.4%* | 14% | −11,060 |
| **P** | 0.75 | 1 | **2.19** | +20.7% | 30% | −5,080 |
| **Y** | 1.0 | 1 | **1.91** | +9.7% | 12% | −3,300 |
| **RB** | 1.25 | 1 | **1.72** | +6.1% | 16% | −2,950 |

\*AU 保证金高，组合内需降 util 或剔除。

**低保证金等权书（HC+RB+M+Y+P+CF+SR，均 roll 门控 + 各品种最优 thr）**

| 指标 | 值 |
|------|-----|
| Sharpe | **≈ 3.79** |
| 累计收益（100万） | **≈ +7.4%** |
| 有仓日占比 | **≈ 50%** |
| 最差日 | **≈ −779** |

对比：`spread` 模块 HC carry **无门控** Sharpe 3.23、有仓 46% —— roll 门控 **降低暴露**，Sharpe 仍高，更适合作 **卫星**。

---

### 3.2 ★★ 交割月 / 预交割（近月 outright）

**逻辑**：进入交割月后，近月向现货/仓单成本收敛；多头移仓、仓单压力等常带来 **近月相对远月偏弱**（品种差异大，需分品种验证）。

```
若 in_deliv_month：做空 rank1 近月（1 手）
或 pre_deliv（交割月前15日）：同上
```

**事件研究（2018+，全窗口内被动持有，非参数搜索）**

| 品种 | 方案 | Sharpe | 备注 |
|------|------|--------|------|
| **CF** | 交割月空近月 | **1.68** | 与天气腿同品种但 **逻辑独立**（制度 vs 温降水） |
| **CJ** | 预交割空近月 | **2.20** | 样本较短，需继续 OOS |
| **CJ** | 交割月空近月 | 1.36 | |
| AG | 交割月空近月 | 0.08 | 尾部大（−36k），**不宜裸上** |
| RB/HC | 交割月空近月 | <0.5 | 黑色系交割月效应弱 |

**结论**：交割月 outright **仅 CF/CJ 有弱可交易性**；其余品种优先走 carry 腿，不做纯交割月单边。

---

### 3.3 ★ 换月动量（main 合约）

**逻辑**：移仓完成后，新主力短期延续旧趋势（ momentum ）。

```
若 pre_roll 且 |main_mom5| ≥ 2%：沿 mom5 方向做多 main，hold 10
```

**样本**：AP 等个别品种 Sharpe ~0.8，**未达卫星标准**；暂作观察，不进组合。

---

### 3.4 ★ 日历月（非天气）

**逻辑**：固定月份做多主力（与农历消费弱相关，**不用天气因子**）。

```
若 cal_month == m：做多 main，hold H
```

| 品种 | 月 m | hold | Sharpe |
|------|------|------|--------|
| **I** | 11 | 15 | **1.34** |
| CF | 12 | 3 | 1.01 |

铁矿石 11 月效应可能与 **钢厂补库 / 采暖季** 日历相关；需与黑色 Core 仓位 **保证金总帽** 协调。

## 4. 进组合 v3 的建议结构

```
组合日历腿 = Σ 各品种 roll门控 carry 盈亏 × 权重
权重原则：等权或按 1/保证金 归一；单品种 util ≤ 0.15
总日历腿占组合保证金预算 ≤ 10%（与 spread 文档一致）
```

| 优先级 | 内容 | 动作 |
|--------|------|------|
| **P0** | HC + RB roll carry 书 | 与 Core 品种重叠但因子正交；先 blotter |
| **P1** | + Y/P/M carry | 扩大分散 |
| **P2** | CF/CJ 交割月小权重 | 仅当与天气 v3 信号 **不同日** 或降权 0.5 |
| **暂缓** | AU/J 换月 carry | 保证金 / 最差日过大 |

**与 combo v3 叠加**：日历腿日收益建议分母仍用 **300万**；需在 `export_combo_v3_blotter.py` 增加第五袖套输入（未完成）。

## 5. 风险与局限

1. **主力规则**：rank1/2 按到期序，与交易所真实主力（OI 最大）可能偏差 → 下一步用 **OI 最大** 对照（见 spread §5）。  
2. **交割月 outright**：AG/AU 尾部风险大；必须 **整数手 + 账户 blotter** 后再定权。  
3. **与 spread 重叠**：carry 因子相同，差异在 **roll 门控**；两者勿 double count。  
4. **样本选择**：2018+ 对齐其他卫星；J 等品种存在 **单次 −3万** 日损。  
5. **制度变更**：限仓、交割品级调整会导致结构性断点，需分年 robustness。
