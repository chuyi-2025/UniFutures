# S1 与 daily/linear 定稿对齐回测

> 脚本：`code/experiment/s1_aligned_blotter.py`  
> 产出：`data/infer/results/daily/linear/s1_aligned.json`、`s1_aligned_daily.csv`

对齐规则与 `final_scheme` 相同：账户 100 万、一手保证金 ≤5 万、整数 1 手、BOOK≥1.18 全平、shouxufei 开平手续费、`log1p((盈亏−费)/100万)`。  
信号仍为 S1：`rule_edge|no_dianping|L30|uniform|single` + 滞回 enter0.4/exit0.1/hold5/hi0.55（只在可交易池内选）。

---

## 结果对比

| | S1 对齐（2024-03~2026-09） | final_scheme 全样本（2010~） | final_scheme 2026 |
|--|---------------------------|-----------------------------|-------------------|
| 收益 | **+12.3%** | +89%（更长） | +4.1%~+4.5% |
| Sharpe | **1.88** | 1.24 | **~2.0–2.3** |
| 最大回撤 | **−1.2%** | −4.0% | −1.3% |
| 空仓 | **51%** | 35% | ~55% |
| 手续费 | ~1.6k（约 2.5 年） | ~1.9k/年 | — |

### S1 分年（对齐后）

| 年 | 收益 | Sharpe | 回撤 | 空仓（约） |
|----|------|--------|------|-----------|
| 2024 | +8.5% | **3.21** | −1.2% | 较低 |
| 2025 | +3.8% | **1.54** | −0.9% | 中等 |
| 2026 | **−0.2%** | **−0.21** | −1.2% | **~81%** |

2026 重叠段（165 日）：S1 Sh **−0.21** vs final **+2.26**，日收益相关仅 **0.10** —— 两套信号几乎不相关，且当年新闻线明显弱于价量定稿。

---

## 解读

1. **扣费+保证金+BOOK 之后，研究里的 Sh≈2.9 掉到 ~1.9**，仍好于 final 全样本 Sh，回撤更小，但不再是“研报截面神器”。
2. **高保证金品种（如 AG）被 5 万帽剔除**，而过拟合归因里 AG 曾是最大贡献之一 → 对齐后收益来源被砍。
3. **2026 空仓极高**：研报单品种覆盖变稀 + BOOK/滞回，导致几乎不交易，略亏；定稿价量线同年仍稳赚。
4. 与 daily/linear **不能互相替代**；更像低相关卫星，且近期（2026）需要覆盖恢复才有交易。

## 去掉 BOOK 后

同一套保证金/1手/手续费，仅关闭 `BOOK≥1.18` 全平：

| | 有 BOOK | **无 BOOK** |
|--|---------|-------------|
| 收益 | +12.3% | **+16.2%** |
| Sharpe | 1.88 | **1.92** |
| 最大回撤 | **−1.2%** | −2.9% |
| 空仓 | 51% | **29%** |
| 手续费 | 1.6k | 1.9k |
| 2025 | +3.8% / Sh1.54 | **+6.3% / Sh1.98**（空仓≈0） |
| 2026 | −0.2% / Sh−0.21 | **+0.8% / Sh0.36**（空仓 56%） |

BOOK 额外掐掉约 **137** 个本有信号的交易日。去掉后收益和 2025/2026 略好，Sharpe 几乎不变，**回撤大约翻倍**。2026 仍远弱于 final_scheme（Sh~2.3），主因仍是信号/覆盖，不是 BOOK。

产出：`s1_aligned_nobook.json`。

## 去掉保证金帽 + 去掉 BOOK（仍 1 手 + 手续费）

可交易池恢复为「有合约乘数/保证金参数即可」，AG/AU 等可重新入选。

| | 有帽+BOOK | 有帽无 BOOK | **无帽无 BOOK** |
|--|-----------|-------------|-----------------|
| 收益 | +12.3% | +16.2% | **+19.6%** |
| Sharpe | **1.88** | **1.92** | **0.82** |
| 回撤 | −1.2% | −2.9% | **−7.3%** |
| 空仓 | 51% | 29% | 28% |
| 2024 | +8.5% / 3.21 | +8.5% / 3.21 | +1.7% / 0.38 |
| 2025 | +3.8% / 1.54 | +6.3% / 1.98 | +14.9% / 1.32 |
| 2026 | −0.2% / −0.21 | +0.8% / 0.36 | +2.3% / 0.36 |
| 在场保证金 | ~受 5 万/腿约束 | 同左 | 均约 **9.2 万**，P90 **22 万**，最高 **34 万** |

持仓日数靠前：AO / NI / **AG** / PG / SM / … / **AU** —— 贵金属回来了，但按 100 万账户、1 手计，波动被放大，**Sharpe 明显变差**，2024 甚至变弱。与 final 2026 相关 **−0.14**。

产出：`s1_aligned_nocap_nobook.json`、`s1_aligned_nocap_nobook_daily.csv`。

python3 code/experiment/s1_aligned_blotter.py
