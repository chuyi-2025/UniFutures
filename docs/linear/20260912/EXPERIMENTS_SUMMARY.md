# UniFutures 线性因子实验总结

> 汇总 `code/experiment/` 脚本及后续讨论中的方案与回测结论。
> 默认样本：**2010-07-01 ~ 2026-09-07**，约 3929 个交易日，**77 个主连品种**（早期更少）。
> 基准组合：截面多空，多头侧 50% 等权 + 空头侧 50% 等权。

## 8. 当前定稿（整数手数 + 保证金）

样本 2010-07-01 ~ 2026-09-08。账户 **100 万**。每品种整数 **1 手**（不把 0.3 手向上取整）。一手保证金按东方财富期货 **2026-09-09** 券商比例（含加收）× 当日收盘估算，超过上限的品种当日不选。盈亏按 `方向 × 价格 × 交易单位 × 涨跌`，Sharpe 用 `log1p(日盈亏 / 100万)`。空仓目标 20%–50%，回撤 10% 以内，每天最多 6 个品种。

不设保证金上限、金/银/锡/股指各开 1 手时，等权 Sharpe 会失真（一手名义差一个数量级），做不到 Sharpe>1 且回撤&lt;10%。

搜索脚本：`code/experiment/pos64_margin_cap_search.py`，结果 `data/infer/results/linear_factor/pos64_margin_cap_search.json`。

| ---- | ------ | ---- | ---- | ----------- | ---- | ------------ |

## 11. BOOK 与手数规则说明

**BOOK 波动比**（策略自身，非市场）：

```
BOOK = 策略近20日收益波动(年化) / 过去252日该波动的中位数
```

| BOOK   | 手数 | 结构        |
| ------ | ---- | ----------- |
| ≥ 1.1 | 2 手 | 1 多 + 1 空 |
| < 1.1  | 6 手 | 3 多 + 3 空 |

**账户收益（1 手模型）**：`leg_pnl × (实际手数 / 6)`，未占用保证金视为现金无收益。
