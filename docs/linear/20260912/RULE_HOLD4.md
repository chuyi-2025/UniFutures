# 规则新闻因子 — 4 品种 / 持仓≥7 天约束筛选

> 脚本：`news/code/train/rule_factor_hold4_screen.py`  
> 回测窗：2024-03-08 ~ 2026-09-08

---

## 1. 硬约束

| 约束 | 实现 |
|------|------|
| **每日最多 4 品种** | 固定 **2 多 + 2 空**（`pick_ls_n`, n_each=2） |
| **持仓中位数 > 7 天** | **sticky hold**：调仓后持有 N 个交易日再换仓；到期若无新信号则延续原仓 |
| **策略尽量简单** | 仅 `rule_edge` / `rule_lex` / `core_lex`；等权 `uniform`；无 ML |

---

## 2. 推荐方案

### 方案 A（综合最优，Calmar 最高）

```
信号：rule_edge = 0.5×标题规则 + 0.5×词表
文档：no_dianping（去掉上涨/下跌点评）
窗口：L=7 自然日，uniform 等权
持仓：hold=10 个交易日，2 多 2 空
过滤：无 min_docs（md0/md1 结果相同）
```

| 指标 | 数值 |
|------|------|
| IC | 0.024 |
| IR | 0.116 |
| Sharpe | **2.25** |
| 收益 | **+88.1%** |
| 最大回撤 | **−6.6%** |
| **Calmar** | **4.55** |
| 持仓中位 | **10 天** |
| 日均品种 | 4.0 |

**分年：**

| 年 | 收益 | Sharpe | 回撤 | 天数 |
|----|------|--------|------|------|
| 2024 | +30.1% | 2.52 | −4.9% | 200 |
| 2025 | +28.6% | 2.44 | −6.6% | 243 |
| 2026 | +12.3% | 1.63 | −4.8% | 165 |

```

```

| 方案 | 持仓中位 | 品种数 | IC | IR | Sharpe | Calmar | 说明 |

## 4. Calmar 比率说明

**定义：**

$$\text{Calmar} = \frac{\text{CAGR（年化复合收益）}}{|\text{最大回撤}|}$$

衡量「每承担 1 单位最大回撤，能换来多少年化收益」。

| Calmar | 评价 |
|--------|------|
| **< 0.5** | 差：回撤相对收益过大 |
| **0.5 ~ 1.0** | 一般：期货量化常见下限 |
| **1.0 ~ 2.0** | 较好：收益/回撤比健康 |
| **2.0 ~ 3.0** | 好：机构可接受的上游 |
| **> 3.0** | 很好：方案 A/B 均在此档 |
| **> 4.0** | 优秀（需警惕过拟合/样本短） |

本批结果中 **Calmar 最高 4.55**（方案 A），但样本仅 ~2.5 年，实盘应预留折扣。  
实务上 **Calmar ≥ 1.5** 可视为「回撤控制合格」，**≥ 2.5** 可视为「较好」。
