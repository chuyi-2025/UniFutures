## 3. 各策略实现说明

### 3.1 量价策略（`final_scheme`）

**定位**：组合 **Core**，决定主节奏与空仓日。

**实现要点**

1. **账户**：100 万人民币；每品种最多 **1 手**；当日截面最多约 **4** 个品种。  
2. **宇宙**：一手券商保证金 ≤ **5 万**（排除 AU/AG/CU/股指/SC 等高保证金品种）。  
3. **信号**：  
   - `pos64` 截面：**1 多 + 1 空**  
   - RSI 截面：**1 多 + 1 空**  
   - 同向合并、反向抵消。  
4. **风控 BOOK**：  
   `BOOK = σ(近20日策略收益) / median(σ, 过去252日)`（滞后 1 日）  
   → `BOOK ≥ 1.18` **全平空仓**。  
5. **成交**：收盘出信号，次日开盘成交；扣交易所标准手续费（shouxufei）。  
6. **脚本**：`code/experiment/pos64_rsi_overlay_2026_blotter.py`；日更 `run_final_scheme.sh`。  
7. **产出**：`data/infer/results/daily/linear/final_scheme_*.csv/json`。

**不是**：神经网络；纯截面规则 + 波动率闸。

---

### 3.2 新闻策略（Dual-Gated V1）

**定位**：挂在 Core 上的 **卫星**，禁止独立重仓替代 final。

**实现要点**

1. **新闻腿**：规则因子族（定稿侧为 `rule_edge` 等可解释规则；滞回/持有约束见新闻文档）。  
2. **门控（关键）**：仅当 **final 当日合计保证金 > 0**（Core 有仓）时，才叠加新闻盈亏。  
3. **权重**：新闻腿乘 **w≈1.25**（门控加权）。  
4. **容量**：新闻侧 util 很小、单腿风险与保证金帽受限（与 capacity 实验同族；Dual 以「不破坏 final 四条件」为目标）。  
5. **审计结论**：2026 official 段可通过「赚更多 / 容量 / 日损」等门；**2024–25** 用 proper BOOK 重建后，最差日仍可能破 −1 万级 → 多年份需继续控尾。  
6. **产出**：  
   - 2026：`news_dual_gated_2026_daily.csv`  
   - 多年 spine：`news/data/results/rule_capacity_dual/audit/dual_gated_v1_proper_book_daily.csv`

**组合里用法**：直接取 Dual 日盈亏作为「量价+新闻」合并袖套，不再把新闻与 final 重复加总。

### 3.3 天气策略（v3 定稿）

**定位**：农产品 **正交卫星**（棉花 / 白糖 / 苹果 / 红枣）。

**实现要点**

1. **数据**：Open-Meteo 中国主产区日值 → 产区加权 → **T-1** 对齐期货主力收益。  
2. **配置**：`weather/config/crop_regions.yaml`（物候窗）。  
3. **v3 四腿（Phase3 搜索，优化 2024+）**：

| 品种 | 因子 | 模式 | thr | hold | 方向 | 物候 |
|------|------|------|-----|------|------|------|
| 苹果 | `tmean_z_ma10` | sign | 1.25 | 15 | +1 | 是 |
| 棉花 | `tmean_z_ma5` | sign | **1.5** | 5 | −1 | 是 |
| 白糖 | `tmean_z_ma5` | long_only | 1.0 | 15 | +1 | 是 |
| 红枣 | `neg_precip_z` | long_only | 1.0 | 15 | −1 | 否 |

4. **Book**：四腿日收益 **等权平均**（研究回测：`signal × log fwd_ret`）。  
5. **为何弃 v1**：v1 含棉花 thr=0.5，2024+ 棉花腿夏普约 −0.62，拖垮等权书（对齐窗天气 Sh 仅 0.18）。  
6. **组合代理**：日研究收益 × **500,000** 名义 → 人民币近似盈亏（**尚未**保证金/手续费 blotter）。  
7. **脚本**：`weather/code/search_weather_phase3.py`；产物 `picked_book_daily_v3.csv`、`phase3_summary.json`。

### 3.4 宏观策略（账户方案 A，本金 300 万）

**定位**：贵金属 **正交卫星**（与 final ≤5 万宇宙互补，主做 AU）。

**实现要点**

1. **因子**：`usd_broad_z60`（贸易加权美元 60 日 z）。派生数据来自 FRED/Yahoo（见 `macro/config`）。  
2. **规则**：`long_only`，z ≥ **0.25** → 做多 AU；持有 **5** 日。  
3. **账户**：启动资金 **300 万**；整数手；券商保证金；手续费；`util=0.35`；`max_lots=2`；`margin_cap=20万`。  
4. **搜索**：`macro/code/search_macro_account.py`（规则网格，无神经网络训练）。  
5. **落盘**：`macro/data/results/search_account/best_account_daily.csv`；镜像 `macro_account_best_daily.csv`。  
6. **组合内降权**：盈亏 × `(0.12/0.35)`；若 Dual 保证金=0（Core 空仓）再 × **0.5**，降低同周期尾部叠加。

### 3.5 组合策略（Core–Satellite v3）

**结构**

```
组合日盈亏 = Dual(量价+新闻门控)
           + 宏观A盈亏 × 0.12/0.35 × (0.5 if Core空仓 else 1.0)
           + 天气v3研究收益 × 500,000
组合日收益 = 组合日盈亏 / 3,000,000
```

**原则**

1. **不做收益排名轮动**；用门控与保证金预算。  
2. 量价与新闻高度相关 → 新闻只能门控卫星。  
3. 宏观 / 天气更正交 → 独立袖套。  
4. 峰值风险看 **最差日/总保证金**，不是只看夏普。  

**相对单一策略**

- 对齐窗累计盈亏约 **59.5 万**，高于 Dual（23.6 万）与任一单袖套。  
- Sharpe **3.49**；2024–2026 **三年夏普均高于**表中单袖套。  
- 代价：最差日可到约 **−1.7 万**（300 万盘），需账户级止损/保证金总闸。

**日线**：本目录 `combo_v3_daily.csv`。
